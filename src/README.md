FITLOG - Workout Library

FITLOG is a modern fitness web app that helps users easily discover, manage, and track their daily workout routines. It features a clean dark-mode design and smooth state management to make planning workouts simple and efficient.

Technologies Used
 Framework: Next.js (App Router)
 Language: TypeScript
 Styling: Tailwind CSS
 State Management: React Context API
 Icons Library: Lucide React
 Notifications: React Toastify

Key Features
 Easy Plan Management: Add workouts to today's plan or save them for later with just one click.
 Live Summary: Automatically shows the total number of workouts, total time in minutes, and calories burned.
 Sort Workouts: Easily sort exercises by duration, calories, or ratings based on your needs.
 Instant Toast Alerts: Clean notifications with progress bars for successful actions, duplicate warnings, and item removals.
 Responsive Dark UI: Works smoothly on phones, tablets, and computers with features like "Mark as Done" and easy tab switching.
